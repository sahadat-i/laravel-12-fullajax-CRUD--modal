## Project Laravel 12 Datatables Server-Side

Ini adalah proyek latihan yang mencakup implementasi <b>CRUD</b> menggunakan Bootstrap 5.3 modal. Salah satu fitur utamanya adalah pengelolaan data Lecture dengan proses <b>Create, Read, Update, dan Delete (CRUD)</b> yang dijalankan melalui <b>AJAX</b>, serta integrasi DataTables server-side untuk pemrosesan data yang lebih efisien dan responsif.

Fitur-fitur inti meliputi:

💡 Bootstrap 5.3 untuk tampilan modern dan responsif

⚙️ AJAX CRUD untuk manipulasi data secara real-time

📊 DataTables (Server-side) untuk pemrosesan data besar secara efisien

✅ SweetAlert untuk notifikasi yang lebih user-friendly

🧩 Struktur kode modular dan mudah di-maintain
